# Contributing

Feedback is welcome on definitions, prior literature, mathematical assumptions, experimental design, fairness, and reproducibility.

Please open a GitHub issue describing the claim or section, your proposed correction, and supporting evidence. For substantive changes, include a clear rationale and, where relevant, a testable prediction. Do not include confidential or personal data.

No contributor license agreement or open-source license has been selected yet; discuss rights and reuse before submitting substantial code or text contributions.
